二、已经完成的架构
============================================================

最终链路：

Open Yami 编辑器/试玩窗口
  -> hud-overlay.js：原有 DanJuan 大盘与 Views 页面系统
  -> ai-agent.js：AI 助手 UI、模型设置、对话、确认/取消
  -> ai-host.js：隔离的本机 Agent Host
       -> DeepSeek/OpenAI 兼容 HTTP API
       -> 插件内置 yami-mcp 子进程（JSON-RPC stdio）
            -> 工程文件与 TypeScript 编译器
            -> 5967 编辑器动作桥
            -> 5966 试玩运行时桥

职责边界：

1. hud-overlay.js
   - 暴露 window.__DANJUAN_HUD_API__ 页面扩展点；
   - AI 页面通过相同 Views 契约注册；
   - 不承载模型和 MCP 业务逻辑。

2. ai-agent.js
   - 动态加入主页【AI 助手】入口；
   - 提供模型地址、模型名、API Key、执行模式设置；
   - 提供聊天、状态、等待确认、执行修改、取消修改、新对话；
   - Enter 发送，Shift+Enter 换行；
   - 自定义 div 按钮提供 role=button、tabindex=0、Enter/Space 激活；
   - API Key 不保存在 localStorage。

3. ai-host.js
   - 监听 127.0.0.1:5968；
   - 使用本机令牌保护所有请求；
   - 调用 DeepSeek 或任意 OpenAI Chat Completions 兼容端点；
   - 自动启动插件内置 yami-mcp；
   - 模型最多连续执行 12 轮工具调用，防止失控循环；
   - cdp_eval 不暴露给内置模型；
   - 文件写操作永远要求确认；
   - 编辑器/试玩操作在“自动模式”下可自动执行，文件修改仍必须确认；
   - Windows 下 API Key 通过当前用户 DPAPI 加密后保存；
   - 配置目录默认位于 %APPDATA%\DanJuanDevSuite；
   - 模型响应和配置接口从不返回明文 API Key。

4. 5966 试玩桥（probe-core.js）
   - 只在真实游戏工程页面启动，不再让编辑器页面抢占端口；
   - GET /live：性能、场景和运行状态；

   - GET /token：只允许无 Origin 的本机 Node 客户端读取；
   - POST /action：要求 x-yami-bridge-token；
   - 允许的动作：键盘、指针、结束卡住事件、暂停诊断类别、恢复作弊状态；
