## 3. 严格数据规则

导出根节点是 10×10 二维数组。每格必含：

```json
{
  "name": "边境哨所",
  "icon": 0,
  "Passability": { "down": true, "right": false },
  "levelRange": { "min": 5, "max": 30 },
  "monsters": [
    { "id": "d4bf5e107664f5c1", "lvMin": 5, "lvMax": 30, "weight": 1 }
  ]
}
```

必须保持：

1. 旧 Excel 通行串第一位映射 `right`，第二位映射 `down`。
2. `icon=-1` 是“无地点”，不是空地；`icon=0` 是合法图标，不能按假值丢弃。
3. 真实图标值完整覆盖 `-1`、`0..7`、`100..102`；未知整数也允许编辑并以“自定义”显示。
4. `levelRange` 可选；有等级无怪物的格子仍必须保留等级。
5. `monsters` 必须是数组；GUID 为 16 位十六进制，等级为正整数，权重大于 0，同格 GUID 不重复。
6. Excel 第 11 行/列以后只有格式残留时裁剪并提醒，有真实值时导入失败。
7. 任何校验错误都会标记地图格、进入可点击诊断列表并禁用下载。

## 4. 已实现的生产工作流

### 选择与导航

- 单击：只选当前格。
- `Ctrl/Cmd + 单击`：切换离散选择。
- `Shift + 单击`：从锚点选择矩形。
- 点击行号、列号：整行或整列选择。
- “全选”或 `Ctrl/Cmd+A`：选择 100 格。
- 方向键：移动主格；`Shift+方向键`：扩展矩形选择。
- `Escape`：收束为主格。
- 鼠标中键拖动，或按住空格再左键拖动：平移放大后的地图；拖动结束不会误选格子。

### 编辑与历史

- 单格：名称、完整图标色板、自定义整数图标、右/下连线、地点等级、怪物列表。
- 多格：批量图标、连线、等级、清空名称/刷怪、复制主格刷怪、主格完整覆盖。
- “复制/粘贴”或 `Ctrl/Cmd+C/V`：单格可填充多个目标，多格可从一个起点保持相对位置粘贴。
- “撤销/重做”或 `Ctrl/Cmd+Z/Y`：最多 100 条历史。
- `Delete/Backspace`：把所选格恢复为空对象。
- 文本和数字连续输入只建立一条历史基线，撤销恢复输入前内容。

### 安全与反馈

- 非法 GUID、等级、权重和图标输入即时标红。
- 错误格带醒目标记；点击诊断项直接选择对应格。
- 新建、再次导入和离开页面时保护未导出的修改。
- 下载成功后清除“未导出”状态。
- 拖入 `.xlsx` / `.json` 时显示全屏投放提示。
- JSON 预览放入按需弹窗，不再常驻挤占检查器。

### 工程资源

- 与角色编辑器共享 IndexedDB：`loot-smith-settings` / `last-project-handle`。
- 已授权时自动读取同一个上次工程；权限失效时显示“加载上次工程”；“选择/更换工程”始终可独立选择新位置。
- 工程只读，不获得写权限；地图 JSON 仍通过下载导出。
- 角色目录严格以 `Data/manifest.json` 的 `actors` 为准，当前真实工程为 63 个角色。
- 名称解析复用 `attribute.json` + `localization.json`；头像支持角色继承与 `clip` 裁切。
- 刷怪行显示头像、名称、GUID 和路径；添加时按名称、GUID、路径搜索，仍允许直接输入 GUID。
- 地形图标从 `地图icon自动切换图标.77ac144f81197913.event` 动态读取分支注释与图片 GUID。
- 地图格默认 64px，真实地标图形位于上方，12px 地点名称固定在图标下方；滚轮范围 44-112px。
- 属性检查器选格后从右侧向左滑入，可独立关闭。
- 格子悬停提示中的刷怪项优先显示“角色名称（GUID）”；未读取工程时回退为 GUID。

## 8. 剩余边界

- 未选择工程时只校验 GUID 格式/重复；选择工程后，引用不存在的 Actor 会阻止导出。
- 撤销历史仅存于当前页面内，刷新后不恢复。
- 工作台针对 10×10 固定地图设计；不是可变尺寸地图编辑器。
- JSON 加载器已修异步等待和路径处理，但 manifest 登记、统一入口事件和按 weight/lvMin/lvMax 刷怪算法仍按原方案阶段 3 单独处理。
- 发布前仍需用户明确要求，不要自动提交、推送或部署。
