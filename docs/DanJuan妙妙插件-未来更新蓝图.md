## 1. 产品定位与目标用户（写功能前必读）

- 插件名：**DanJuan妙妙插件**（仓库「bajibaji/yami-tools」，「extension」分支，SSOT 母仓库）。

## 4. v0.6.0 详案：调试控制台 + 变量挂件

### 4.1 入口与形态

- 主页新增**第 5 卡「调试控制台」**（Views.register('cheats')，第 6 页 page-cheats）。
- 页面 = 大按钮开关式，零输入零概念：每个能力一个开关/按钮 + 一行白话说明。
- 同时新增**变量 Pin 挂件**（不占页面）：胶囊（右上角 FPS 条）下方半透明便签条，常驻显示 3~5 个钉住的变量。

### 4.2 作弊能力清单（每项都查证过引擎源码）

| 能力 | 小白文案 | 实现依据与要点 |
|---|---|---|
| 游戏变速 | 【加速】1x / 2x / 5x / 10x 大按钮（+0.5x 慢放可选） | 高倍速=循环前设「Time.deltaTime = 16.6」再循环调「Game.update()」（跳渲染）。注意：「Game.update()」**无参数**；直接改「Time.timeScale」会被 time.ts:64「Math.min(deltaTime, tpf+1, maxDeltaTime=35)」截断，无效 |
| 穿墙 | 【穿墙】开关 | 「Party.player.passage = -1」（actor.ts:1646「if (passage === -1) continue」实锤忽略地形碰撞）；关闭时还原原值 |
| 移速加成 | 【加速跑】开关 | 「ActorNavigator.setMovementSpeed(12)」（默认 4）；还原 |
| 锁血 | 【锁血】开关 | 血量是 **Attribute 属性系统**（无 hp 字段，已实测）——每帧把主角 HP 属性刷满；关闭停止 |
| 秒杀 | 【秒杀】开关 | 遍历「Scene.actor.list」跳过主角，把怪物 HP 属性归零；注意锁血与秒杀都要经属性读写 |
| 主角瞬移 | 【点哪里飞哪里】模式按钮 | 开启后点游戏画面 → 摄像机坐标换算世界坐标 → 主角 x/y 赋值（复用场景实体页坐标换算思路） |
| 后台时间漂移提示 | 变速台一行灰字 | 监听页面隐藏/失焦：记录真实时间与游戏内推进时间差，显示"本次后台 5 分钟，游戏内仅推进 21 秒"——**只检测不补算**（自动补算会触发连锁事件，不可控） |

### 4.3 变量 Pin 挂件

- 存档台【变量与开关】里每个变量右侧加【固定】按钮，最多钉 5 个。
- 胶囊下方便签条：变量名 + 当前值，每 500ms 刷新，鼠标穿透（不挡游戏操作）。
- **类型异常红标**：hook「Variable.set」原型——检测写入类型与目标类型不符（引擎 variable.ts:118 会**静默丢弃不报错**）或值为 NaN 时，便签条该变量标红并显示白话提示【类型异常：写入被引擎丢弃】。这是盲点的最小闭环：让"悄悄丢失的赋值"变成看得见的警告。

## 5. v0.7.0 详案：事件指令流水 + 幽灵事件侦探

### 5.1 入口与形态

- 并入「控制台报错」页，升级为**「运行日志」**（页面内分区：报错 / 事件流水 / 翻译检查）。
- 事件流水：最近 20 步环形队列，每行 = 时间 + 事件名 + 动作（启动/执行/挂起/等待）+ 白话描述。

### 5.2 事件指令级时间线

- 小白场景："角色不动了、剧情不继续了，控制台没任何报错" → 打开运行日志，一眼看到"最后停在【等待玩家按键】第 3 步"。
- **核心实现难点（已预研）**：指令函数是编译产物（匿名闭包，无名称）。取"当前执行到哪条指令"的方法：hook「EventHandler.prototype.update」，读「this.index」，再经「Data.events[事件id].commands[index]」反查原始指令「{id, params}」得到指令名与参数摘要。挂起态识别：「update」返回 false 且 index 未推进 = 挂起/等待。
- 白话描述映射：常见指令预先翻译（如「setNumber」→ "设置数值【金币】=100"、「wait」→ "等待 500 毫秒"、「showChoices」→ "弹出选项"），未识别的指令显示原始 id。

### 5.3 幽灵事件侦探

- 扫描「EventManager.activeEvents」：显示每个挂起事件的**已挂起时长**（如"已等待 182 秒"）。
- 深度探测：事件闭包引用的宿主（角色/界面节点/触发器）若已「destroyed: true」，标红【幽灵事件：宿主已销毁】。
- **一键终止**：调「event.finish()」拔除滞留引用，阻断内存泄漏（对应引擎盲点：普通挂起事件零监控，仅 Stats.debug 下查 independent 1 分钟）。

## 6. v0.8.0 详案：存档安全体验

### 6.1 存档台改动 Diff 草稿（并入存档管理页）

- 顶部【变更草稿】浮层：列出本次会话所有"已修改未保存"项（如 金币: 100 → 99999）。

## 7. 不做清单（用户裁决，勿再提议）

| 功能 | 不做理由 |
|---|---|
| 输入宏录制回放 | 随机数（暴击/闪避/掉落）导致回放失效，成本极高；作弊台秒级可达同样测试目的 |
| 调试绘制层（碰撞线框/触发框/寻路折线画面上） | 用户裁决不需要 |
| UI 检视器（节点边界高亮） | 用户裁决不需要 |
| 画面射线拾取器线框 | 同上 |
| 性能基线快照对比 UI | 小白理解成本高——底层数据接口保留，UI 不主推 |
| 离线时间自动补算 | 会触发连锁事件不可控——只做检测提示（见 4.2 末行） |

## 8. 工程铁律速查（开工前必读）

1. **入口上限**：主页 5 入口封顶；报错页升级为「运行日志」后其余功能归入对应页。
2. **小白文案**：中文白话、零英文键名、零代码残留、零 Emoji；内部英文枚举必须经中文映射再进 UI。
3. **术语铁律**：actor=角色、particle=粒子、ui=界面、trigger=触发器、event=事件、scene=场景、camera=摄像机、texture=纹理（禁"微粒/UI 元素"）。
4. **勿改引擎与游戏框架源码**：「D:\Documents\GitHub\2」与「D:\new-game\Script/*.ts」只读；框架行为变更走游戏工程「Assets/插件/全局插件/」monkey-patch；本插件全部能力经原型 hook 实现，零侵入。
5. **开发流程**：仓库根（extension 分支）开发 →「node build.cjs」（CSS 注入+20 锚点+SSOT 版本断言+术语/Emoji 三源自检）→「node build.cjs --deploy」（单向镜像生产目录 + MD5）→ 真机 F5。
6. **版本**：新功能 Minor（x.Y+1.0）；发布前版本号三源同步（manifest / probe PROBE_VERSION / hud 兜底）+ HANDOFF 当前版本 + README。
7. **Git 口令铁律**：用户未说"Git 上去"严禁 commit/push。
8. **测试**：每版新增自回归脚本放「.e2e-tmp/」（不入库），发布前全量跑（verify / autoupdate / errflow / scene-lab + 新脚本）。
