## 3. 架构分层

```
┌─────────────────────────────────────────────────────┐
│  视图层（React）                                      │
│  左侧包树(5包+计数+子目录开关) │ 主区(文件/动画组双视图+搜索+虚拟滚动) │ 右信息栏(预览/标签/收藏/素材单/导出) │
├─────────────────────────────────────────────────────┤
│  预览/导出引擎                                        │
│  Canvas 播放器(序列/sheet/GIF) · 缩略图懒生成(Worker) · gifenc(GIF) · PNG 导出(命名模板) │
├─────────────────────────────────────────────────────┤
│  索引层（内存 + IndexedDB）                           │
│  fileIndex(文件) · animIndex(动画组) · packPresets(包规则) · fixes(手改) │
│  tags(文件标签) · favorites · collections(素材单) · searchHistory · prefs │
├─────────────────────────────────────────────────────┤
│  摄取层（File System Access API / webkitdirectory 降级）│
│  全量扫描(首次) → 增量扫描(mtime/size) → 包预设识别 → 聚类动画组 │
└─────────────────────────────────────────────────────┘
```

### 关键数据结构（IndexedDB）

- `files`：{ rel, pack, dir, name, ext, size, mtime, dims? }（主键 rel）
- `anims`：{ id, pack, dir, type(seq/sheet/gif/single), name, fps, frames:[rel], loose }
- `tags`：Rel -> [tag]；`tagNames`：标签去重列表
- `favorites`：[rel]
- `collections`：{ id, name, createdAt, items:[{ rel, order, note }] }（素材单=技能集合）
- `fixes`：{ animId, name, fps, order:[rel], members:[rel] }（手改覆盖）
- `packProfiles`：{ pack, presetId, rules: { seqRegex, sheetMeta: txt|json, sheetDirPattern, gifFirst, fps, ... } }
- `thumbs`：{ key(rel+size), blob }（LRU 上限缓存）
- `prefs`：{ exportTemplate, viewMode, lastPack, searchHistory, ... }

## 4. 核心交互流程

1. **打开**：自动重连授权 → 增量扫描（首次全量，显示进度）→ 左树显示 5 包 + 动画数
2. **浏览**：点包 → 默认文件平铺列表（虚拟滚动 + 懒缩略图）；点切换 → 动画组视图；打开"子目录"开关 → 看到包内文件夹层级
3. **预览**：点任意文件/动画 → 右侧播放（序列按帧序、sheet 按元数据/alpha 切分/手动参数、GIF 原生）；带 fps/缩放/循环/帧条
4. **整理**：选中 → 打标签（联想） / 收藏 / 加入素材单 / 手动修正（合并、拆分、设 fps、改名）
5. **导出**：当前帧 PNG / 整组帧 PNG / 勾选多项批量导出 / 素材单整单导出（按清单顺序+命名模板）/ GIF
6. **定位**：信息栏复制相对路径；搜索后包计数联动
7. **备份/设置**：命名模板、包规则编辑器、元数据 JSON 导入导出

## 5. 技术栈

已有：Vite 5 + React 18 + React Router (Hash) + framer-motion + File System Access API。
新增：`gifenc`（GIF 编码，约 10KB）、可选 `react-window`（虚拟列表）、Web Worker（扫描/缩略图）。

## 7. 风险与边界

- 浏览器每次重启后可能要求重新授权素材库（可接受，一键点选）
- 无绝对路径 / 不能打开资源管理器 / 不能真拖文件进 Explorer（网页硬边界，已确认接受）
- 首次全量扫描 + 首次缩略图加载会慢（预计 1–3 分钟/按需生成），之后增量秒开
- 元数据只存浏览器 → 用 JSON 备份兜底
- GIF 编码大图/长动画慢 → 后台队列 + 进度提示
