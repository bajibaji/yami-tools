# 挂机游戏实际游玩逻辑链（代码推理）

> 2026-08-12 从 `D:\new-game` 源码/数据/存档推理。
> 来源：`Assets/! 事件/`、`Assets/UI/地图/`、`Assets/技能/`、`Assets/角色/`、`Assets/插件/`、`Assets/场景/`、`Script/command.ts`、`Save/save00-03.save`。
> 本文件描述**游戏当前真实实现**，不是最终设计。游戏为开发早期 Demo，多处为示例/测试残留。

## 0. 一句话结论

当前游戏是一个**手动操作的动作刷怪 Demo**，不是挂机游戏：玩家在大地图选目标 → 走进地下城 → 手动（按住右键连击）击杀 30 只怪 → 走到出口触发重刷 → 刷到终点后无限往返。**没有任何自动战斗、离线收益、自动刷怪循环、自动推进机制**。挂机验证台模拟的"全自动挂机"与游戏现状形态不符，且核心数值模型（怪物成长、攻击间隔、命中判定、升级成长）与游戏实现存在多处出入。

## 1. 大地图与地图推进

### 1.1 世界地图数据
- `Assets/UI/地图/地图格.34eee41059f43f30.xlsx` 五工作表 → 10×10 网格：
  - 名称（50 个命名地点）、等级区间（如 `5～30`）、图标（`-1`=无地点，`0`=起点王城，`1-7`=野地，`100/101/102`=城镇）、通行串（`第一位 right / 第二位 down`）、刷怪列表（怪物 GUID 逗号分隔，`-`=无怪）
- 通行数据 `地图通行数据.9e8282a5917c31db.json`：10×10 grid + `blockedEdges`（8 条封锁边），游戏内存于全局 `地图icon分部`/`地图icon连线`。

### 1.2 推进流程
```
大地图点击目标 → A* 寻路（自定义指令「数组模拟寻路」，四方向，图标<0 为障碍）
  → 玩家终点X/Y = 目标格，路径点 = 整条路径（不含起点）
  → 「前往目的地」：首次到达=TRUE，上一张地图X/Y=当前
  → 取路径点.shift() → 玩家所在地图X/Y = 下一格
  → 当前地下城名字 = 地图名称[y][x]；icon/等级区间同步取出
  → 怪物最低/最高等级 = 解析 "min～max"
  → 按 icon loadScene：100/101/102 → 城镇场景（写保存点）；3 → 沙漠道路；其余 → 森林道路
```
- 玩家可到达地点 = 首次到达某地图时 BFS 向四邻域解锁（`icon>=0` 且边界内）——地图是**渐进解锁**的。

### 1.3 关键：怪等级区间只影响"等级随机"，缩放是线性的
- 怪物模板 create 事件：`怪物最低/最高等级 > 0` 时，等级 = `random-int(min, max)`，否则用基础等级。
- 随后立即调「升级事件」做全属性缩放：**每个属性 += 等级差 × 1**（线性）。

## 2. 地下城流程（核心循环）

### 2.1 刷怪（场景「刷怪」事件 → `地下城自动执行.c583e18db0816773.event`）
1. 读全局 `地图刷怪列表[所在地图Y][所在地图X]`（Excel sheet5）→ 怪物 GUID 列表。
2. `loop count < 30` 内嵌 `forEach monsterList`：每只怪用 `new Actor(data)` 生成，team=魔物队，位置 = 刷怪区域 `getRandomPosition(0)` 随机点，`Scene.actor.append`。
3. 无怪列表时兜底刷 30 只史莱姆。
4. 触发时机：**场景创建时**（`地下城创建.cf82a008cc8583bc.event`）与 **到达出口时**。

### 2.2 赶路进度
- 地下城创建时 `赶路进度 = 0`（全局变量初始 100，仅在进图时清零）。
- 走到出口 region：若所在地图 ≠ 终点 → 进度 += 100，**全队传送回入口 + 重刷**（中间图走两遍）。
- 进度满且路径点还有剩余 → 调「前往目的地」推进下一张地图。
- 所在地图 == 终点 → 同样传回入口 + 重刷 → **终点变成无限刷怪农场**（无限往返）。
- 城镇出口 → 回大地图。

### 2.3 场景结构（森林道路/沙漠道路/地下城模板）
- 刷怪区域 region（autorun 注册到全局 `地下城刷怪区域`）
- 入口/出口 region（playerenter 触发；出口触发「到达地下城终点」）
- 地图终点 actor（宝箱，autorun 注册到 `地下城目标`）

## 3. 怪物行为（`基础怪物AI.261596a4f32a8550.event`，每怪独立事件循环）

```
记录出生点 → 随机延迟 0~1000ms → 死循环：
  待机: 若被定身(眩晕属性>0) 等待；detectTargets(警戒范围，基础怪=5格，enemy)
       → 有目标跳战斗；无目标：每 10 tick 随机方向游走一段
  战斗: 每 100ms 轮询；getTarget nearest（距离>50 丢弃）
       → 距离≤1：停步、面向目标、castSkill 普攻(900-攻击)，攻击后继续轮询
       → 距离>1：followActor 追击（circle，min 0.5 / max 1）
  返回: resetTargets + 导航回出生点
```

### 3.1 怪物攻击节奏（关键公式）
```
SPDTime = attackTime × attackSpeed + attackSpeed-base × 10   （毫秒）
```
- 史莱姆：attackTime=1.85、attackSpeed=1（模板默认）、attackSpeed-base≈80 → 约 0.8 秒/次。
- **attackTime 属性 ≠ 实际攻击间隔**，实际间隔由 SPDTime 决定，攻击速度加成起主导作用。

### 3.2 怪物成长（通用怪物模板「升级事件」，create 时调用一次）
```
lv = 修正等级 − 基础等级
maxHealth += lv；health += lv；maxMana += lv；mana += lv
attack += lv；mAttack += lv；hit += lv；dodge += lv
rewardExp += lv；rewardJobExp += lv；level = 修正等级
```
线性成长，每级：HP/攻击/命中/闪避/经验 全部 +1。

## 4. 玩家战斗（手动）

### 4.1 操作
- 左键点击：寻路移动（按住持续跟进）；右键：攻击（**按住每 180ms 自动循环施放普攻**，并行指令，是当前唯一的"半自动"）；WASD 移动；1-9 技能栏；滚轮 1/2 档缩放。
- 技能施放条件（`技能施放条件判断`）：状态 ∈ {闲置, 连击-1}；MP ≥ 消耗；通过后扣 MP。
- 冷却：`最终冷却 = 基础冷却 × (1 − 冷却缩减% × 0.01)`。

### 4.2 伤害公式（`计算物理伤害公式` / `计算魔法伤害公式`）
```
物理: damage = atk × 技能系数 ÷ 100 − 目标物防 − 目标基础物防
魔法: damage = matk × 技能系数 ÷ 100 − 目标魔防 − 目标基础魔防
atk   = 基础攻击 + 物理攻击 + 攻击百分比加成 × 0.01
matk  = 魔法攻击 + 基础魔法攻击 + 魔法百分比加成 × 0.01
技能系数 = 技能属性 29f7b43644ef24ab（默认 100 = 100%）
```
- 命中：`hit = 命中率 + 基础命中率 − 目标闪避 − 目标基础闪避 − random×80`；`hit < 0` → MISS。**无 5% 下限**。
- 暴击：`random < 暴击率` → damage ×2（暴击率>0 时优先判定；=0 直接走命中）。
- 最低伤害：`damage < 0 → 1`。
- 护盾吸收；持续施法可被打断（强韧=0 时 50%）；生命偷取：`伤害 × 生命偷取%` 回血；仇恨 `changeThreat += 伤害`。

### 4.3 击杀结算（`处理技能伤害` → `击杀后获得经验值`）
- 目标 HP ≤ 0：
  - 队伍成员：死亡事件（若全队死亡 → 游戏结束界面），播死亡动画，不删除。
  - 怪物：先给经验 → 死亡事件 → 掉落事件 → 死亡动画 → `deleteActor`。**怪物不复活**。
- 经验：`forEach 队伍成员`（在场 active 成员）每人 `经验值 += 奖励经验值`、`职业经验 += 奖励职业经验值`。
- 升级判定：`经验值 ≥ 最大经验值` → 调角色「升级事件」，超出的经验扣除。

### 4.4 升级（通用英雄模板「升级事件」）
```
守卫: 等级 < 100
等级 += 1
下一级经验: expMax = floor(10**((lv−1)×0.1) + lv×100)
剩余PT += floor(等级×0.2 + 2)        ← 手动加点用
!switch 职业: 自动成长分支            ← 带 ! 前缀，运行时被跳过，不生效！
health = maxHealth；mana = maxMana   ← 满血满魔
```
- **当前玩家升级只涨等级、PT 点、满血——不自动成长属性**（职业自动成长指令全部被禁用）。
- 属性提升靠：PT 手动加点（`属性加点按钮` → 主菜单派生公式）+ 装备。

### 4.5 派生属性公式（`主菜单_!基础属性_更新`，加点/装备后的最终值）
```
最大生命 = ceil(rate × baseHP)，rate = 1 + VIT×…（含百分比加成）
最大魔法 = 1 + INT×…
基础攻击(远程职业) = floor(DEX×0.1) + …；魔法攻击 = floor(INT×0.125) + …
基础攻击速度 = 80 + …；暴击 = 1 + …；基础命中/闪避/回血/回魔/施法缩短 各有公式
```
- 派生公式细节较多，验证台直接读最终属性即可，不必复刻。

## 7. 挂机现状结论

| 机制 | 游戏现状 |
|---|---|
| 自动战斗 | ❌ 无；只有"按住右键 180ms 循环普攻"的半自动 |
| 自动寻怪/索敌 | ❌ 怪物 AI 索敌，玩家不自动找怪 |
| 离线收益 | ❌ 无 |
| 自动刷怪循环 | ⚠️ 半自动：场景创建刷 30 只、到出口重刷；无定时器 |
| 自动推进关卡 | ❌ 需手动点大地图 |
| 死亡复活 | ❌ 无复活；队伍全灭 → 游戏结束 |
| 挂机时长收益 | ❌ 无 |

**"挂机"目前只有两层地基**：怪物 AI 主动索敌攻击 + 地下城自动刷怪重刷。玩家侧完全手动。

## 8. 验证台（tools/idle-lab）模型差距清单

### 8.1 已对齐（无需改）
- 伤害公式 `atk×系数/100 − 防御`（含基础防御两段相减）✓
- 最低伤害 1 ✓；暴击 ×2 ✓
- 金币期望 `(min+max)/2 × dropRate` ✓（史莱姆 50.5 对上）
- 地图 10×10 / 50 地点 / 10 战斗关 / 通行串方向 ✓
- 属性继承解析、文件名 Lv 优先级、属性组限定 ✓

### 8.2 模型不一致（需要改）
| # | 维度 | 验证台 | 游戏实际 | 影响 |
|---|---|---|---|---|
| 1 | 怪物等级成长 | 指数 `hpGrowth=1.08^delta`、`atkGrowth=1.055` | **线性** `属性 += 等级差`（HP/攻/命/闪/经验各 +1/级） | 高等级怪强度差数倍，瓶颈判定失真 |
| 2 | 攻击间隔 | `interval = attackTime`（史莱姆 1.85s） | `SPDTime = attackTime×attackSpeed + attackSpeed-base×10`（≈0.8s） | 单场战斗时长差 ~2.3 倍 |
| 3 | 命中判定 | 概率 `(baseHit+hit−dodge)/100`，下限 5% | 阈值 `命中+基础命中−闪避−基础闪避−random×80 < 0 → MISS`，无下限 | 高闪避怪命中率模型不同 |
| 4 | 战斗形态 | 1v1 顺序刷怪 + spawnDelay | **30 只怪同场围攻**（仇恨/多目标） | 生存率、击杀节奏完全不同 |
| 5 | 经验分配 | 单人 | **全队在场成员分享** | 数值差队伍人数倍 |
| 6 | 死亡 | reviveSeconds=8 复活 | **无复活**；全灭 → 游戏结束 | 死亡惩罚模型错误 |
| 7 | 升级 | 买攻击升级（+百分比） | 升级 = 等级+1 + PT 手动加点（**职业自动成长被禁用**）；PT 按 `floor(等级×0.2+2)/级` | 推演成长曲线错误 |
| 8 | 经济 | 只算金币 | 每怪必掉 3 件装备（100%）+ 金币；拾取延迟 1s、30s 销毁 | 经济指标缺装备项 |
| 9 | 推进规则 | 通关即下一关（BFS 排序） | 中间图走两遍（赶路进度）、终点图无限往返、城镇中转、保存点 | 挂机流程推演不符 |
| 10 | 地图解锁 | 全部可达 | **首次到达 BFS 渐进解锁** | 高级关不可直达 |

### 8.3 验证台推演了但游戏当前没有的（属"目标态"，保留但标注）
- 全自动战斗、离线收益、自动刷怪循环、自动推进关卡、技能树多资源养成。

### 8.4 建议修正优先级
1. **先改数值模型**（§8.2 1-3）：怪物线性成长 + SPDTime 攻击间隔 + 阈值命中——这三项改动即可让单场战斗结果贴近游戏。
2. **再加形态**（§8.2 4-5）：多怪围攻 + 全队经验。
3. **死亡规则**（§8.2 6）按"无复活、全灭即终点"修正。
4. 经济（§8.2 8）把装备掉落计入指标（或标注当前模型不含装备价值）。
5. 推进规则（§8.2 9-10）等游戏挂机机制明确后再改——当前游戏连挂机都没有，推演结果只作"目标态"参考。

## 9. 附：游戏侧下一步建议（按挂机化推进）

1. **先定"挂机"定义**：挂机 = 站桩自动战斗？还是地图自动推进？还是离线收益？三者实现成本递增。
2. 最便宜的第一步：**自动攻击开关**——把"按住右键 180ms 循环"变成定时器自动循环（已有循环代码可复用）。
3. 然后：**自动索敌/自动拾取**（拾取已有吸引圈机制，可加"自动吸引半径"）。
4. 再后：**自动推进**——到达出口自动调用「前往目的地」。
5. 最后才考虑离线收益（存档时间差结算）。
