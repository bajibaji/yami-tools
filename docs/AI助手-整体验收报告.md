## 五、仍未验证 / 已知限制

1. **真机 GUI 走查未做**：AI 面板、计划卡片、改动小结卡片、差异预览、授权勾选、撤销面板的真实渲染与键盘可达性，只在 DOM 结构层面被断言过，未做像素级走查。
2. **试玩中的冒烟未实测**：`playtest_smoke` 的"真实游戏里"路径未跑过（模拟桥测试通过，但真机需要编辑器在跑且人工点试玩）。
3. **编辑器侧 5967 桥受限于隔离世界**：插件在当前引擎构建运行于隔离世界，`File.save`/`Title.playGame` 这类引擎内部 API 取不到；工程文件的读写走文件系统（可靠），编辑器内的"立即刷新"依赖引擎自身的窗口聚焦重扫。
4. **子代理委派与计划模式未做**（P2，不影响本工程日常使用）。
