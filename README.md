# DanJuan妙妙插件 (Open Yami 开发者非侵入式辅助套件)

> **版本**：`v1.5.1`  
> **分支**：`extension`（母仓库单一真实源 SSOT）  
> **定位**：面向 Open Yami RPG Editor 编辑器的原生非侵入式辅助套件，包含**性能排查大盘（Profiler）**、**运行日志工作台（报错 / 事件流水 / 幽灵事件侦探）**、**发布前工程体检（Project Audit）**、**存档管理台（Save Lab）**、**场景实体检查台（Scene Inspector）**、**作弊与调试控制台（Cheats）**、**变量监视挂件（Pin）**以及微内核页面契约架构。

## [核心特性]

1. **零工程侵入与零构建依赖**：
   - 纯原生 JS 开发，以 Electron MV3 扩展形式注入主线程（`world: "MAIN"`）；
   - 0 外部 npm 依赖、0 外部 CDN 字体/网络请求，单机局域网或断网环境下 0 依赖秒开。
2. **正统 Remix Icon 离线免联网标准**：
   - 100% 采用官方开源 **Remix Icon（Line 风格）** 纯矢量 Path 内联呈现；
   - 全局界面恪守**绝对零 Emoji 规范**，深度契合 Yami 原生暗黑工业质感。
3. **运行日志工作台（控制台报错 + 事件黑匣子）**：
   - **全局异常拦截**：拦截 `window.onerror`、`unhandledrejection` 与 `console.error`；
   - **引擎级专属白话诊断库**：内置空指针属性名解析、公共事件死循环/爆栈、场景地形与 Autotile 越界、插件指令参数、WebGL 图形管线、音频解码、NaN 无效计算等 11 类典型异常智能归因与排查建议；
   - **同类高频错误指纹聚合**：帧循环同源异常自动聚合并累计计数展示 `[xN次]` 醒目徽章，彻底根除死循环刷屏；
   - **源码就地高亮与定位直达**：就地展开报错行上下 7 行源码代码块并高亮标记出错行，提供【定位文件】一键调起系统资源管理器直达物理文件；
   - **多维分类过滤与实时搜索**：`全部`、`高频`、`空指针`、`方法丢失`、`插件指令`、`场景地形`、`资源404`、`控制台` 标签自适应弹性换行平铺，支持输入框关键字检索；
   - **一键导出 Markdown 诊断报告**：包含硬件环境、游戏运行状态、场景、FPS/DrawCall 以及全部异常详细调用栈与源码片段，一键复制并自动落盘；
   - **事件指令级时间线**：最近 20 步事件流水（启动/执行/等待/挂起/结束），经编译期建立的「原始指令 ↔ 编译槽位」映射把运行下标翻译回**「第几步 + 那条指令在做什么」**白话描述（如「等待 500 毫秒」「弹出选项（2 项）」），剧情卡住时一眼看到停在哪一步；
   - **幽灵事件侦探**：列出卡住不动的事件与已停住时长，所属对象（角色/界面元素/触发器）已被删除时红标【所属对象已被删除】，并可**一键结束**卡住的事件（调用引擎原生 `finish()` 拔除引用）；
   - **发布前工程体检**：纯静态扫描 `Data/*.json` 与 `Assets/`，检查**引用丢失**与**死事件**。结果**按 ID 折叠**（同一 ID 被引用 N 次只出一条，带 `xN` 与涉及文件列表）并**按影响分级**：
     - **[会影响运行]** 图片/立绘/素材已不在工程里 → 游戏里会显示不出来；
     - **[可能失效]** 属性已从属性表删除，但事件指令还在给它赋值 → 引擎会把它编译成空函数（`command.ts:478` `Function.empty`），**不报错也不生效**；
     - **[历史遗留]** 只有角色/资产里还留着已删属性的初始值 → 载入时被默默忽略（`variable.ts:256`），不影响运行；
     - **[死事件]** 全工程任何位置（指令、界面资产绑定、脚本按 GUID 或按名字）都找不到引用，可以放心删。
     **合法 ID 三源判定**：资产注册表（文件名 + `Data/*.json`）∪ 资产文件内部定义的 `id`（界面元素属性键等）∪ 节点自注册预设——避免把合法引用误报成断链；真机对照：模板工程 0 问题，改版前 `D:/new-game` 报 203 条、改版后折叠为 102 条并按影响分级。
4. **存档管理台 (Save Lab)**：
   - **双环境智能感知**：自适应识别试玩独立窗口（`location.pathname`）与编辑器宿主环境（`page-frame[value="home"]`），全自动跟随打开工程的存档目录；
   - **中文变量元信息解密**：精准读取游戏变量中文字典、分类文件夹（如常用变量、系统变量、地下城等）与真实类型（布尔/数值/文本），布尔型 100% 绑定工业级 Toggle 开关；
   - **常用速改与 JSON 树形图**：支持领队金币、坐标直接修改与深层存档数据可视化编辑；
   - **三大子面板满高自适应**：弹性链路纵向贯通，最大化利用屏幕可用垂直空间；
   - **变量写入被丢弃的定位**：引擎对类型不符的写入是**静默丢弃**（`variable.ts:117-133` 无兜底分支）；插件捕获后不只报症状，而是直接告诉用户**是谁写的**——「事件《新手村剧情》· 第 2 / 3 步 · 设置文本 · 场景：新手村」，展示在变量行下方与监视小窗里。
5. **双重硬核物理级鼠标穿透**：
   - 采用高特异性复合选择器（`.yami-perf-dock.show.through`）与 JS 行内最高优先级控制；
   - 穿透时侧栏半透明，鼠标直通底层游戏画面，顶栏保持交互可随时退出。
6. **多层 UI 联动隐身机制**：
   - 侧栏大盘展开（或开启穿透）时，右上角常驻迷你胶囊自动联动隐藏，收起时自动恢复，杜绝半透明叠画穿帮。
7. **微内核页面契约体系 (Microkernel Page Contract)**：
   - 页面统一遵循 `Views.register(id, { mount, refresh, destroy })` 标准契约；
   - 消除巨型单文件的闭包耦合，扩展新功能如“即插即用”。
8. **自动化版本管理与单一事实源断言**：
   - 构建脚本内置版本号单一事实源（SSOT）自动化校验锁，杜绝漏改；
   - **整包快照更新**：一次下完 GitHub 分支快照（`archive/refs/heads/extension.tar.gz`，大陆直连实测 588 KB / 2.2 秒，失败自动换反代通道），内存解包 → 校验（manifest 声明的文件必须都在包里、每个 JS 过一遍语法解析）→ 备份旧版本 → `.tmp` + 原子替换，`manifest.json` 最后落盘；**校验不过就原地不动**，写盘失败自动回滚，绝不半更新（教训见铁律㊵）；
   - **装机范围 = 整包内容 − 开发目录黑名单**：新增文件自动进包，不再依赖任何人工维护的文件清单；
   - **离线兜底**：面板常驻「本地安装」，手动下载整包解压后选那个文件夹即可升级或重装，全程不依赖外网通道。
9. **场景实体检查台 (Scene Inspector)**：
   - 实时检视当前地图同屏实体：场景放置与全局角色分组、坐标、可见性、碰撞体积（圆形/矩形直径、可推动性）与主角归属；
   - 触发区域矩形范围与当前区内角色名单，展开行可查导航器移动模式/速度、动画播放器状态与通行信息；
   - 地图信息顶卡 + 搜索/类型过滤/「仅可见」开关，500ms 节流轮询与快照比对杜绝高频重建。
10. **内存与缓存 (Resource Cache)**：
   - 对标引擎盲点：`loader.ts:19-23` 的三张缓存表（图片 / objectURL / Blob）**只增不减**，长时试玩内存持续爬升，用户只会归因成「电脑不行」；
   - 白话统计（图片缓存 N 张 · 正在加载 M 张 · 临时数据 X MB · 已用内存 Y MB）+ 状态徽标（正常 / 加载中 / 偏多）；
   - **安全的一键清理**：有资源正在加载时**直接拒绝**（加载器 `complete === false`），清理时跳过加载中的条目、同步清掉 objectURL 并释放 Blob，避免"下次重新加载拿到失效链接导致图片裂开"；只由用户点击触发，绝不进心跳轮询（铁律⑲）；
   - **引擎构建差异照实说明**：部分引擎构建不暴露资源加载器（真机实测 `Loader` 取不到，而 `Data`/`Command`/`EventHandler` 可达），此时卡片自动降级为「[仅内存]」、只报内存占用并隐藏清理按钮，**绝不假装可用**。

11. **AI 全能副驾 (AI Assistant & 内置 yami-mcp)**：
    - **在场自然语言开发**：在 Open Yami 内通过主页【AI 助手】直接向大模型提需求，用白话修改工程代码、编排事件、配置数据与控制试玩；
    - **流式对话（实时可见）**：回复逐字上屏，每次工具调用都作为一行过程条实时显示（`执行：读取脚本 · Assets/xxx.ts` → `完成`），失败标红，不再"干等转圈"；
    - **随时打断，打断后立刻能继续**：生成中点【停止】或按 Esc 会**真的**停下来（取消会一路传到模型请求与工具执行，不再"说停还在改文件"），而且停完马上就能说下一句——不会卡在「上一条需求还在处理中」（这一条曾是真实故障：取消时主动 destroy 只触发 close 不触发 error，任务悬在 await 上、会话被永久锁死）；
    - **视图自动停在最新，但绝不打扰你翻历史**：生成过程中视图跟着最新内容走（思考的单行预览显示**最后一行**，即它此刻在想什么）；你一旦往上滚就立即松开跟随，新内容只在底部留一个「↓ 有新内容」提示，视口一个字都不动，滚回底部或点提示即恢复跟随；
    - **会话历史与恢复**：每段对话自动落盘（`%APPDATA%\DanJuanDevSuite\sessions\`），工具栏【历史】可切回任意旧对话继续；关窗口、重启编辑器、隔天回来都不丢；
    - **思考过程可回看**：思考内容随会话一起落盘，切回旧对话时连同当时的思考块一起回放（展开 / 单行预览 / 折叠三档显示方式同样适用），不是只有正文；
    - **思考按轮次分块 + 过程智能收起**（对齐 DSH 的 Chat 语义）：一轮需求里"思考 → 调工具 → 再思考"的每一轮推理**各成一块**（段头 `第 2 段 · 已思考 X 秒 · Y 字`，各自独立折叠）；一轮跑完时把过程行收成一行 `思考 14 秒 · 3 段 · 5 步`，正文照常可见——紧凑/标准两档可切（默认紧凑），**没有最终正文的轮次不收起**（那轮只剩过程证据），**键盘焦点在过程里时也不收起**；
    - **每轮用量行**：轮末如实报 `本轮 4 次调用 · 18.2k tokens · 约 0.0061 元`（悬停看输入/缓存命中/输出明细）；**记账不全就整行不显示**，不拿部分总量冒充完整结果；
    - **工具卡片 + 一键定位**：每次工具调用是一张卡片——状态点（运行中/成功/失败/待确认）、中文工具名、目标路径（**点一下就在文件夹里定位**）、事实标签（`+12 / -3 行`、`命中 7 处`、`退出码 0`），点开看细节与错误原文；**超长输出会被如实标注「已截断」并把完整原文落盘**（给出可打开的路径），绝不假装完整；
    - **系统提示词看得见**：模型这一轮实际读到的 system 原文做成一行可折叠项（文本变了才再上一行），排查"它为什么不听话"时不用猜；
    - **忙的时候说话不再石沉大海**：输入区始终只有一个发送按钮，AI 干活时按发送的行为由【设置 → 繁忙时发送】决定——**排队**（默认，进排队区、本轮结束后依次发出、可单条撤回）或**打断**（停掉这一轮，立刻发这条）；另有 Ctrl+Enter 快捷键把补充**插进正在跑的这一轮**（不打断，在下一个步骤边界投递）——送达才显示"已送达"，没赶上的如实退回排队区，绝不假装收下；
    - **轮次导航轨道**：聊天区右侧每一轮一个刻度，滚到哪一轮就高亮哪一个，点刻度跳过去、悬停看那一轮的预览，长对话里不用一直滚滚滚；
    - **上下文计量与自动压缩**：按官方口径计量（中文 0.6 token/字、英文 0.3 token/字符，工具 schema 计入），窗口取 1M token；占用达 **80%** 自动压缩——先做不花钱的确定性修剪（长工具结果留头尾），不够再让模型产出八节固定结构的检查点；保留最近 16% 窗口原文；工具栏实时显示「上下文 320k/1M · 32%」并在接近阈值时高亮；
    - **打转保护**：模型若反复调用同一批工具（同名同参），立即止损并如实告知，不再空转到步数上限；
    - **一键撤销（改错能退回去）**：每次写盘前自动备份并记录"谁改的、什么时候"；工具栏【撤销】只列**本对话里 AI 改过的文件**，一点退回它动手之前，回退前先存当前内容所以**回退也能再撤回**；向导出的 `Data/manifest.json` 这类派生索引禁止回退；
    - **任务计划与进度**（`todo_write`）：多步需求先列白话清单，每完成一步更新状态，界面上用一张计划卡片原地刷新，过程条同步显示「进度 N/M，正在做：…」——长任务不再"闷头干"；
    - **工程内检索**（`search_project`）：按正则/关键词在脚本、数据表、事件里定位，命中带文件+行号+匹配位置与上下文行——先搜再改，不再整份读大文件；
    - **脚本精确修改**（`edit_script`）：按片段替换而不是整份重写；片段不唯一会拒绝并给出行号，`dryRun` 先预览差异，写入后强制编译校验，编译不过自动回滚；
    - **试玩冒烟测试**（`playtest_smoke`）：让 AI 按脚本驱动一遍游戏（`"down,down,ok"`），跑完自动对比运行时诊断，直接告诉你「有没有新报错、有没有事件卡住、性能是否恶化」——改完代码不用你手动点试玩验证；
    - **运行时诊断直达**（`diagnose_runtime`）：把试玩里采集的报错黑匣子压成 AI 能直接下结论的清单——报错按指纹聚合，每条带可疑文件名、行号、就地源码与白话归因，另附卡住/幽灵事件、最耗时更新器与渲染器；「游戏里报错」不再是靠猜；
    - **隔离 Agent Host 架构**：监听 `127.0.0.1:5968`，Windows DPAPI 硬件级加密保存 API Key，支持 DeepSeek 云端与任意本地 OpenAI 兼容端点（如 Ollama / llama.cpp）；
    - **严格写盘安全门禁**：只读工具自动执行；所有文件写操作永远先预览并等待开发者确认，自动备份到 `.yami-mcp-backups` 并支持哈希防冲突校验；
    - **会话内批量授权**：批准写盘时可勾选「本次任务内该文件不再逐条确认」，之后只有这个文件免打扰（删除类永不授权）；授权可在【撤销】面板里随时取消，执行时也有过程条提示；
    - **5966 / 5967 双桥控制**：免开 9222 调试端口，原生支持工程保存、撤销、重做、试玩、控件交互与试玩键盘/指针模拟；
    - **真实 TypeScript 编译门禁**：脚本写入强制调用引擎原生 `tsc.exe`，编译报错自动撤销回滚。

## [安装与加载方式]

1. 打开 **Open Yami RPG Editor**；
2. 将本分支下的文件放置于：
   `[Open Yami 安装目录]/extension/yami-perf-extension/`
3. 启动编辑器并进入游戏试玩：
   - 右上角常驻迷你帧数胶囊（FPS / 耗时 / DrawCall）；
   - 按 **`Home`** 键或点击胶囊随时呼出/收起主控大盘；
   - 点击右上角【穿透】胶囊按钮，随时边玩边调；
   - 点击主页【AI 助手】即可唤出白话开发智脑。

- **本地修改与自检**：
